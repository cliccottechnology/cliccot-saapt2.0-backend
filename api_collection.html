1. School Class Master CRUD APIs
Base: /api/
The School Class module manages standard academic grades (e.g. "Class 6", "Class 7", "Class 8"). Classes can be referenced by integer ID or string name when creating student profiles and section allocations.
GET /api/list-classes/  or  /api/get-classes/  or  /api/classes/
Bearer Token Required application/json
Retrieves all registered school classes ordered by numerical sequence. Ideal for populating UI dropdown selectors and master data tables.
Response (200 OK)
[
  {
    "id": 1,
    "name": "Class 6",
    "code": "CLS-6",
    "numeric_order": 6
  },
  {
    "id": 2,
    "name": "Class 7",
    "code": "CLS-7",
    "numeric_order": 7
  },
  {
    "id": 3,
    "name": "Class 8",
    "code": "CLS-8",
    "numeric_order": 8
  }
]
POST /api/add-class/  or  /api/classes/
Bearer Token Required application/json
Creates a new class entry. name is required and must be unique. code and numeric_order are optional.
Request Body Parameters
FieldTypeRequiredDescription
namestringRequiredClass display name, e.g. "Class 11" or "Grade 11" (Max 50 chars, Unique).
codestringOptionalUnique shortcode, e.g. "CLS-11" (Max 20 chars).
numeric_orderintegerOptionalSorting rank, e.g. 11 (Default: 0).
Request Body Example
{
  "name": "Class 11",
  "code": "CLS-11",
  "numeric_order": 11
}
Response (201 Created)
{
  "id": 6,
  "name": "Class 11",
  "code": "CLS-11",
  "numeric_order": 11
}
GET PUT PATCH DELETE /api/view-class/<id>/  |  /api/edit-class/<id>/  |  /api/delete-class/<id>/
Bearer Token Required
Retrieve: GET /api/view-class/6/ returns the class object (200 OK).
Update: PUT /api/edit-class/6/ or PATCH /api/edit-class/6/ modifies fields (200 OK).
Delete: DELETE /api/delete-class/6/ permanently deletes the class record (204 No Content).
Edit Request Body (PATCH Example)
{
  "name": "Class 11 - Senior"
}
Edit Response (200 OK)
{
  "id": 6,
  "name": "Class 11 - Senior",
  "code": "CLS-11",
  "numeric_order": 11
}
Delete Response
204 No Content (Empty Response Body)

3. Academic Year Master CRUD APIs
Base: /api/
The Academic Year module defines school terms/sessions (e.g. "2025-2026", "2026-2027"). Supports marking the active current year and date boundary validation. Can be specified by integer ID or string name in student endpoints.
GET /api/list-academic-years/  or  /api/get-academic-years/  or  /api/academic-years/
Bearer Token Required application/json
Retrieves all academic years. Identifies which session is flagged as the current active school year.
Response (200 OK)
[
  {
    "id": 1,
    "year_name": "2025-2026",
    "start_date": "2025-06-01",
    "end_date": "2026-04-30",
    "is_current": false
  },
  {
    "id": 2,
    "year_name": "2026-2027",
    "start_date": "2026-06-01",
    "end_date": "2027-04-30",
    "is_current": true
  }
]
POST /api/add-academic-year/  or  /api/academic-years/
Bearer Token Required application/json
Creates a new academic year session. Setting is_current to true marks this as the default active year.
Request Body Parameters
FieldTypeRequiredDescription
year_namestringRequiredUnique name, e.g. "2027-2028" (Max 20 chars, Unique).
start_datedate (YYYY-MM-DD)OptionalOpening date of academic session.
end_datedate (YYYY-MM-DD)OptionalClosing date of academic session.
is_currentbooleanOptionalFlag indicating if this is the active school year (Default: false).
Request Body Example
{
  "year_name": "2027-2028",
  "start_date": "2027-06-01",
  "end_date": "2028-04-30",
  "is_current": false
}
Response (201 Created)
{
  "id": 3,
  "year_name": "2027-2028",
  "start_date": "2027-06-01",
  "end_date": "2028-04-30",
  "is_current": false
}
GET PUT PATCH DELETE /api/view-academic-year/<id>/  |  /api/edit-academic-year/<id>/  |  /api/delete-academic-year/<id>/
Bearer Token Required
Retrieve: GET /api/view-academic-year/2/ returns the session details (200 OK).
Update: PUT /api/edit-academic-year/2/ or PATCH /api/edit-academic-year/2/ updates dates or flags (200 OK).
Delete: DELETE /api/delete-academic-year/3/ removes an unused academic year (204 No Content).
Edit Request Body (PATCH Example)
{
  "is_current": true
}
Edit Response (200 OK)
{
  "id": 2,
  "year_name": "2026-2027",
  "start_date": "2026-06-01",

7. Authentication & Password Security
Base: /api/auth/
POST /api/auth/forgot-password/
No Auth Required application/json
Forgot Password API (Step 1 - Ask Mail ID & Send OTP): Takes user's registered email address and sends a secure 6-digit OTP code (valid for 10 minutes).
Request Body
{
  "email": "user@saapt.com"
}
Response (200 OK)
{
  "message": "OTP has been sent to your registered email address.",
  "email": "user@saapt.com"
}
POST /api/auth/verify-otp/
No Auth Required application/json
Verify OTP API (Step 2 - Verify Code): Validates the 6-digit OTP code entered by the user. If correct, returns a verification token for Step 3.
Request Body
{
  "email": "user@saapt.com",
  "otp": "582914"
}
Response (200 OK)
{
  "message": "OTP verified successfully. You can now enter your new password.",
  "email": "user@saapt.com",
  "reset_token": "u9mP0q-vA7Xz1bKr_8xL92aBcD4eFgHiJkLmNoPqRs"
}
POST /api/auth/reset-password/
No Auth Required application/json
Reset Password API (Step 3 - Set New Password & Confirm): Takes the new password, confirmation password, and reset token to update the password.
Request Body
{
  "email": "user@saapt.com",
  "reset_token": "u9mP0q-vA7Xz1bKr_8xL92aBcD4eFgHiJkLmNoPqRs",
  "new_password": "NewSecurePass@2026",
  "confirm_password": "NewSecurePass@2026"
}
Response (200 OK)
{
  "message": "Password changed successfully. You can now log in with your new password."
}
